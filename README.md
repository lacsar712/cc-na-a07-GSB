# 航标灯光巡检台

登记航标实测光强和方位偏差，服务端当场给出合格或不合格。两条实测可留存成一张对照单：亮度差、偏角差由服务端在留存时写入存档，之后按灯号随时翻开旧单；来源实测被改正后，旧单仍显示留存时的差并标注"来源已变动"。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3190 |
| 应用 | http://localhost:8190 |
| PostgreSQL | localhost:54390 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| keeper | light123456 | 可登记 |
| watch | watch123456 | 只读 |

## 启动

```bash
cd projects/11-nav-aid-inspection
docker compose up --build
```

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格。
2. 再登记一条光强低于要求的记录，结论为光强不足。
3. 换 watch 登录，没有登记入口；直接提交登记会拒绝。
4. 对照单：keeper 进顶栏"对照单册"→"新开对照单"，实测一选 LH-01（明亮种子 1400）、实测二选 LH-09（偏暗种子 800），留存后亮度差为 600。
5. 到 LH-09 详情点"改正"，只改实测光强保存；再打开这张旧单，亮度差仍是 600，并标注"来源已变动"。
6. watch 能翻对照单册、打开旧单，但没有新开入口；直接提交新开或改正都会被拒绝。
